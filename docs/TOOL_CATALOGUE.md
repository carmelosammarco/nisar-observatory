# Active tool catalogue

Seven tools share the preparation, quality, display and export controls.

| Number | Tool | Product |
|---|---|---|
| P01 | Flood Memory | GCOV |
| P02 | Wetland Pulse | GCOV |
| P03 | After Fire Observatory | GCOV |
| P04 | Sinking City Atlas | GUNW |
| P05 | Quake Evidence Explorer | GUNW |
| P06 | Volcano Surface Diary | GCOV |
| P07 | Glacier Motion Pulse | GOFF |


The removed slope workflow, rainfall controls, Eastern Swiss Alps preset and Portuguese Bend investigation are no longer part of the application. Shared GUNW reference-domain corrections remain in P04 and P05. Other retired tools and their presets remain unavailable.

Historical exports retain their original tool numbers. Do not import old job directories into a different application version; rerun the original data with the current corresponding tool instead.


Shared metadata readiness, strict baseline counts, explicit category labels and exported result interpretation apply across the seven tools. P03 combined mode is version 0.8.0 and clips its analysis domain to the selected geographic rectangle. Read [the release record](REFINEMENT_0_8.md) for reproducibility checks and remaining independent-validation work.
