The application is an independent research project for NASA Space Apps. It is not an official NASA/ISRO product, certification, emergency service or operational hazard assessment.

No remote repository has been created or published by this release. A source package excludes personal runtime files and Earthdata sessions. Protected input files require the explicit `--include-example-inputs` packaging option; recorded example outputs and tutorials are included for read-only exploration.
