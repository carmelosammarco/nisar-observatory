# Local introduction video

The About page uses `nisar-observatory-introduction.mp4` (1920 × 1080, 2:53) with the JPEG poster. English captions are burned into the video; the SRT and plain-text transcript are supplied separately. Native controls provide playback, seeking and fullscreen. An Expand video button also provides a large in-app view when browser fullscreen is unavailable. No autoplay, external embed or Earthdata login is needed. Leaving About pauses playback.

This is an edited presentation of genuine app screenshots, a fresh Mozambique Flood Memory result, and explanatory graphics, with synthetic Google Gemini Flash narration. It is not continuous live screen capture.

Credits: app by Carmelo Sammarco; NASA–ISRO NISAR / ASF observations; NASA Scientific Visualization Studio illustration 5661 (https://svs.gsfc.nasa.gov/5661/); Esri/Vantor/Earthstar Geographics and credited place-name contributors. The map images retain their applicable attribution. No NASA endorsement is implied. The flood comparison is qualitative, not independently established classification accuracy.
