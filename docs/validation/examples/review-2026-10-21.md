## What the checks cover

The review compares the actual browser job request with the typed tutorial recipe, checks all processing options and required references, validates numerical regression targets, opens the numeric raster, verifies the opening PNG and its endpoints, and requests every saved map preview. **328 rasters/previews passed.** All 53 tutorial figures and downloadable documents returned successful responses. The only unavailable views are Flood Memory's three recovery maps: all contain no finite recovery values because the example has no observation after the flood date, and each gives a clear explanation rather than an error.


The original published/reference figures and curated result figures remain separate. Fresh review exports are stored as `references/review-opening-map.png` in each Example, without replacing the user-selected card or historical comparison imagery. Each case's `verification.json` records the current job, settings, metrics and per-map checks.

## Corrections and regression


**360 Python tests and 183 frontend tests passed.** One existing Starlette test-client deprecation warning remains; no failed tests. These checks establish engineering reproducibility, not independent scientific accuracy. Each tutorial retains its study-specific limitations, particularly lava attribution, the horizontal-speed assumption, reference stability and spatial representativeness.

## Cleanup

Removed only Finder `.DS_Store` metadata and disposable test/interpreter cache files. See [the exact cleanup receipt](cleanup-2026-10-21.json). Downloaded originals/subsets, all saved runs, reusable scientific arrays, protected inputs, source papers, figures and cited validation outputs were preserved. The large validation folders are supporting evidence and comparison-script inputs; they are not unused application clutter.
