Four L-band products. Four different meanings.

The mission carries L- and S-band radars. This app uses NASA/ASF L-band data only—including local imports and area subsets. Frequency A/B inside these files are L-band subbands, not the two instruments. Data access explained ↗

GCOV

Surface scattering

Calibrated, terrain-corrected radar power. Compare echo strength in dB, screen quality and interpret changes with context.

Used by water, fire and volcano tools.
GUNW

Interferometric phase

Phase differences between compatible observations, with coherence and connected components. Requires a reference and careful correction handling.

Used by subsidence and earthquake tools.
GOFF

Image-pattern offsets

Range and along-track movement components, with matching quality. Outliers need screening; these are not east/north vectors.

Used by Glacier Motion Pulse.
SME2

Soil moisture estimates

Modeled volumetric moisture derived from repeated radar power. Quality flags, retrieval method and provisional calibration matter.

Mission background only; this app has no soil-moisture analysis tool.

Check the spacing for your selected method.

Larger cells reduce processing detail. A smaller setting cannot create detail absent from the source. The actual grid may be coarser to respect the product and area limits; the result reports its spacing.

Native windows above 8 million pixels require a smaller area. P03 combined and P06 evolving use a bounded metric grid: at most 2048 cells per side and four million cells; oversized requests stop rather than silently coarsen. P04/P05 allow up to 900 cells per axis and the other methods 384, with coarser spacing for larger areas.

Native quality support

Quality flags screen original samples before they are averaged. A cell needs enough accepted native support to be retained.

Stricter settings reduce coverage. Regional plots compare exactly the same valid cells across the selected record. A separate grid is used for each product.

EARTHDATA CONNECTION

Your data. Your private session.

Catalog search is public. Reading science arrays requires an Earthdata login or a local file.

Connect NASA Earthdata

L-band data · NASA / ASF. This app uses GCOV, GUNW and GOFF. S-band access is separate; see the explanation alongside.

Searching is public. Select an area and click Find NISAR data without signing in. Connect below to read or download remote measurements. Saved local files and Examples work without a login.

Each person connects with their own Earthdata account here. The app starts disconnected and never automatically signs in. Credentials stay in this server’s memory. They are never written to disk, returned by the API, or included in result exports.

A local science workspace

Why L-band only?

The app’s collections and LSAR readers use NASA/ASF L-band (~24 cm). Earthdata Login authorizes access to many NASA datasets; the account itself does not select the radar band.

NISAR’s complementary S-band (~9.4 cm) uses ISRO Bhoonidhi ↗. S-band login, import and processing are not supported here. Frequency A/B are subbands within a radar instrument, not L/S. Official access guide ↗. See Mission library → L-band data in this app for the comparison.

The service binds to 127.0.0.1. It is designed for your computer, not public hosting. All Python dependencies live in this project’s .venv.

What is saved?

Original files, product/date/time folders of area extracts, run parameters, source IDs and derived results are kept inside data/. New area HDF5 files can be imported manually without their JSON sidecars. Your password is not saved. Restarting the service requires a new login.

When a connection fails

Check the username and password at Earthdata Login ↗. If the account works there, check its ASF application authorizations. You can import supported L-band GCOV, GUNW, GOFF or SME2 HDF5 originals and area subsets. Other mission products and S-band files are not supported.

Read the scientific scope

The installed tools provide exploratory analyses. P04 reconstructs connected GUNW pairs and fits relative LOS rates; other phase tools explain their separate model gates. Delivered ionospheric subtraction is optional and explicit. Full atmospheric/tidal correction, validated forest loss, damage assessment and hazard prediction are outside this release. Each tool explains the supported result and its limits.

THE CHALLENGE I JOINED

Dancing with the SARs

Earth is always moving. The challenge is to make those changes visible.

Earth's surface is an endless dance of natural processes and human activities, but these changes are often difficult to visualize, understand, and communicate. From wetland loss to forest wildfires, earthquakes, farming activities, glacier movement, and more, Earth is in a constant waltz of surface changes.

Your challenge is to build an interactive application that uses radar remote sensing data from the NASA-ISRO Synthetic Aperture Radar (NISAR) mission to track and visualize one or more types of surface change at locations around the world.

FROM AREA TO UNDERSTANDING

Four steps. A traceable result.

  1. Choose an area. Start small, with a rectangle of a few kilometers. Use the map or enter coordinates.
  2. Find and select data. Choose one compatible group per product and several acquisition dates. Catalog hits alone do not guarantee valid pixels.
  3. Run a tool. Connect Earthdata or import files. Choose Prepare. For tools needing a reference, Continue checks the data and suggests patches; you explicitly choose or keep a checked reference before running.
  4. Inspect the evidence. Compare the map and observation chart, read the interpretation, check quality and export the source manifest.
