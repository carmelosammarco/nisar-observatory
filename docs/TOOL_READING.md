# Scientific reading for the current tools

The Tools tab presents general product documentation and scientific background for the ten active tools. Each link has a meaningful title, a short explanation and a clear evidence label. Case-specific papers, input dates, comparison figures and limitations live in the four Examples tutorials.

- **P01 Flood Memory:** Mozambique / Chókwè NASA flood example.
- **P02 Wetland Pulse:** Wheeler Marsh and the paper-inspired HH/HV method.
- **P04 Sinking City Atlas:** Mexico City relative LOS motion comparison.
- **P05 Quake Evidence Explorer:** Venezuela earthquake comparison.

Other active tools retain general scientific reading without claiming a tested local example. `frontend/assets/tool-reading.json` stores the current link groups; `docs/tools.json` stores implemented methods. Retired analyses and their case studies are not served as cards or tutorials. See [the current catalogue](TOOL_CATALOGUE.md) for the complete numbering.
